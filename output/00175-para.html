παρά — без (о времени); несмотря на; чем (лучше…, чем…); только (в конструкции δεν… παρά)

Транслитерация: pará  ·  Часть речи: предлог; также союз и частица (неизменяемое слово)  ·  Род: —  ·  Частотный ранг исходной формы: 289

Неизменяемое слово. Основные конструкции: 1) время: «час + παρά + минуты» — «без …» (δύο παρά τέταρτο — без четверти два); 2) παρά + винительный падеж — «несмотря на» (παρά τη βροχή); 3) καλύτερα / προτιμώ … παρά να … — «лучше…, чем…»; 4) δεν … παρά … — «только, всего лишь». Не путайте с наречием πάρα с ударением на первом слоге: πάρα πολύ — «очень».
