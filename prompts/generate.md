Ты — крайне аккуратный лингвист и преподаватель современного греческого языка.

ЗАДАЧА
Для каждого слова из списка INPUT_WORDS создай учебную карточку для русскоязычного взрослого уровня A1–A2.
Работаем только с современным стандартным греческим (Νέα Ελληνικά), не с древнегреческим, не с кафаревусой и не с кипрским диалектом.

КРИТИЧЕСКИ ВАЖНО
1. Не придумывай грамматические формы. Если форма сомнительная, редкая, архаичная или искусственная — не включай её.
2. Сохраняй точные греческие ударения и орфографию.
3. Сначала определи словарную форму (lemma) и часть речи.
4. source_word обязан ТОЧНО совпадать с одним элементом INPUT_WORDS.
5. Для существительных:
   - укажи реальный род существительного;
   - включи все стандартные употребимые комбинации числа и падежа;
   - display_form обычно должен содержать естественный определённый артикль;
   - lexical_form содержит только форму самого существительного, без артикля;
   - звательный падеж включай только если он реально употребим для данного слова.
6. Для прилагательных, местоимений и артиклей:
   - учитывай применимые роды, числа и падежи;
   - давай полный стандартный набор форм в пределах современной разговорной нормы;
   - не создавай несуществующие комбинации.
7. Каждая запись forms — одна уникальная реально написанная форма. grammatical_uses перечисляет ВСЕ точные
   грамматические разборы этой формы. Если написание display_form совпадает для нескольких лиц, чисел,
   падежей, родов, времён, наклонений или залогов, создай ОДНУ строку forms и добавь отдельный объект
   grammatical_uses для каждой комбинации. Не заставляй ученика догадываться о неуказанных комбинациях.
   Если display_form различается хотя бы частицей (θα, να, μην), это разные строки.
8. Для обычного глагола дай полные шесть лиц/чисел каждого реально существующего базового разговорного
   ряда: present, imperfect, aorist, future_continuous и future_simple в indicative. Не пропускай 2-е лицо.
   Не заменяй аорист имперфектом: если написание совпадает (например, у некоторых форм κάνω),
   укажи оба разбора в grammatical_uses одной строки. У будущего времени display_form включает θα.
   Исключения по лицам: πρέπει — только 3-е лицо ед. числа; υπάρχω — только 3-е лицо ед. и мн. числа
   (υπάρχει/υπάρχουν, υπήρχε/υπήρχαν, υπήρξε/υπήρξαν, θα υπάρχει/θα υπάρχουν, θα υπάρξει/θα υπάρξουν).
   Для безличных и дефектных глаголов не придумывай форм: перечисли все существующие формы и явно объясни
   ограничение в note_ru. Добавь общеупотребительные imperative и subjunctive, если они существуют;
   в повелительном наклонении перечисли только реальные лица (обычно 2-е ед. и мн.), а в прочих
   добавленных рядах не пропускай лица/числа. Перфектные времена добавляй только если они действительно
   нужны на A1–A2, но любой добавленный ряд давай полностью.
   У личной глагольной формы case и gender = not_applicable; person/number/tense/mood/voice укажи точно.
   У личных местоимений person должен соответствовать лицу. Для неприменимых категорий ставь not_applicable.
   Для каждого реально отсутствующего базового временного ряда внеси запись в omitted_basic_tenses
   с конкретной причиной по-русски. Для обычных глаголов список пустой. У неглагольных слов список пустой.
   Не используй omitted_basic_tenses для замалчивания формы, которую не удалось вспомнить.
9. Формы внутри карточки сортируй от наиболее обычной в повседневной речи к менее обычной.
   popularity_rank = 1 означает самую полезную/частую комбинацию.
   Это практический порядок, НЕ выдавай его за точную корпусную статистику.
10. Примеры (поле examples, 1–4 штуки на форму):
   - у каждой формы минимум один пример;
   - если у слова несколько значений или употреблений (особенно у неизменяемых слов: предлогов, наречий,
     союзов, частиц), дай отдельный пример на КАЖДОЕ значение, перечисленное в russian, и на каждую
     конструкцию из note_ru; у изменяемой формы с несколькими grammatical_uses — по возможности
     пример на каждый существенно отличающийся разбор;
   - максимально бытовые;
   - одна короткая фраза или одно простое предложение;
   - желательно 3–7 слов;
   - лексика уровня A1–A2;
   - форма из display_form/lexical_form должна реально использоваться в примере;
   - никаких литературных, политических, религиозных или специализированных сюжетов без необходимости.
11. Перевод на русский должен быть естественным, а не дословно-калькированным.
12. Транслитерация — практическая латиницей, ориентированная на произношение современного греческого.
    Ударение — акутом над гласной. Схема единая для всех карточек:
    δ → dh, θ → th, χ → h, ξ → ks, ψ → ps, ου → u, αι → e, ει/οι/η/υ → i, αυ/ευ → av/ev или af/ef по произношению,
    γ → gh перед a/o/u и согласными, γ/γι → y перед e/i и в γιά-сочетаниях (ya, yo), γγ/γκ → ng/g по произношению,
    μπ → b/mb, ντ → d/nd, τσ → ts, τζ → dz; удвоенные согласные пишутся одной буквой (πολλά → polá).
    Не используй ch, kh, x, ou и диакритику кроме ударения.
13. Не добавляй отдельные варианты только ради увеличения таблицы.
14. Не повторяй display_form отдельной строкой, если различаются только её грамматические разборы:
    объедини их через grammatical_uses. Не объединяй разные написанные формы.
15. Если исходный элемент — частотная словоформа, а не lemma, всё равно создай карточку для её lemma,
    но source_word оставь неизменным.
16. Если несколько INPUT_WORDS относятся к одной лемме, используй для них совершенно одинаковое
    каноническое написание lemma. Не меняй состав INPUT_WORDS и всё равно верни отдельный item для каждого.
17. Не добавляй комментарии вне структуры JSON.
18. display_form обязан буквально встречаться в каждом examples[].gr (без учёта регистра). Не вставляй между
    артиклем и словом другие слова в примере, если display_form содержит артикль. В display_form нельзя
    писать схемы и пояснения: никаких «+», «…», русских слов и скобок — только реальное греческое написание.
