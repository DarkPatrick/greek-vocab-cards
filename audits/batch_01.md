# Аудит 1: первые 10 уникальных карточек

Порядок: по минимальному `rank` в `data/processed.csv`. Карточки проверены без изменения `output/`.

## Повторяемая структурная проверка

Команда: `PYTHONDONTWRITEBYTECODE=1 .venv/bin/python scripts/audit_batch.py --start 1 --count 10`

Все 10 проходят проверку наличия файла и таблицы, уникальности написанных форм, нумерации,
наличия грамматического разбора и транслитерации, совпадения количества греческих примеров,
их транслитераций и переводов, а также присутствия формы в каждом примере.

## Словарная проверка и замечания

| Карточка | Итог | Основание / действие |
| --- | --- | --- |
| `και` | Без обнаруженных замечаний | Сохранены `και` и `κι`; три значения `και` показаны примерами. |
| `ο` | Без обнаруженных замечаний | Показаны 18 сочетаний числа, рода и падежа плюс вариант `τη/την`; сверено с [школьной грамматикой](https://ebooks.edu.gr/ebooks/v/html/8547/2334/Grammatiki-Neas-Ellinikis-Glossas_A-B-G-Gymnasiou_html-apli/index_C_01.html). |
| `να` | Без обнаруженных замечаний | Показаны побуждение, вопрос, зависимая глагольная форма и указательное «вот». |
| `με` | Без обнаруженных замечаний | Три бытовых употребления предлога; омонимия с местоимением оговорена. |
| `για` | Без обнаруженных замечаний | Показаны адресат, тема, цель и длительность. |
| `που` | Небольшой пробел покрытия | В заголовке обещано значение «где», но оба примера показывают только союз/относительное местоимение. Добавить отдельный пример относительного места либо убрать это значение из заголовка. Не путать с вопросительным `πού`; различие подтверждает [Центр греческого языка](https://www.greek-language.gr/certification/sites/greeklanguage.gr.certification/files/KLIK_ANSWERS_B1.pdf). |
| `από` | Небольшой пробел покрытия | Заголовок включает «начиная с», но нет временного примера. Добавить, например, контекст с `από αύριο`; он встречается в [грамматике Триандафиллидиса](https://www.greek-language.gr/greekLang/files/document/modern_greek/grammatiki.triantafyllidi.pdf). |
| `σε` | Существенный пропуск форм | Отсутствуют `στου`, `στης`, `στων`. Их образование прямо указано в [школьной грамматике](https://ebooks.edu.gr/ebooks/v/html/8547/2334/Grammatiki-Neas-Ellinikis-Glossas_A-B-G-Gymnasiou_html-apli/index_C_01.html). Добавить с пояснением конструкции с родительным артиклем. |
| `δεν` | Без обнаруженных замечаний | Формы `δεν/δε` и пример для `δε` согласуются со [словарём](https://www.greek-language.gr/greekLang/modern_greek/tools/lexica/triantafyllides/search.html?lq=%CE%94%CE%B5%CE%BD). |
| `θα` | Без обнаруженных замечаний | Показаны будущее и вежливая условная просьба; оба употребления есть в [словаре](https://www.greek-language.gr/greekLang/modern_greek/tools/lexica/triantafyllides/search.html?dq=&lq=%CE%B8%CE%AC). |

Статус: 10/10 проходят машинную структуру; 1 существенный пропуск и 2 замечания по покрытию значений.
Это не сертификат абсолютной безошибочности переводов и транслитерации: для них нужна отдельная
ручная проверка носителем/преподавателем, особенно в спорных случаях.
